**Переменные и типы данных**

Переменная - это ячейка памяти, с которой мы можем взаимодействовать, видо изменять и проделывать другие виды действия с ней.

    имя переменной                          ячейка памяти
    ┌──────────────┐                     ┌──────────────────────┐
    │      а       │ ──── ссылка ────>   │  Тип  int            │ 
    │ (адрес: 0x..)│                     │  Счетчик ссылок  1   │
    └──────────────┘                     │  Значение  5 (101)   │
                                         └──────────────────────┘

    Имя переменной в памяти хранится в виде еденичек и нулей, на саму переменную записан адрес, который введет в ячейку памяти, где записано, число или какие то данные про переменную.

Переменную можно назвать как угодно, но по строгим правилам, нельзя писать через дефис имена, только нижнее подчеркивание, нельзя использовать ключевые слова языка, нельзя начинать имя переменной с цифры и нельзя использовать пробел, знаки припенания и спецсимволы.
